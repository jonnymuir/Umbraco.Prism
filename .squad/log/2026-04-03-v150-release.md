## Summary

Umbraco.Prism v1.5.0 shipped with a major architectural shift toward zero-consumer-code integration, security hardening, and community governance signals.

## What Shipped

### 1. Zero-Config Azure Key Vault Integration (Blathers + Copper + Mabel)
- **Implementation:** `PrismKeyVaultConfigureOptions` via `IConfigureOptions<PrismBiometricOptions>` pattern
- **Consumer experience:** Add `Prism:VaultUri` to appsettings.json; no Program.cs changes needed
- **Behavior:** Fail-late (errors surface on first biometric login, not at startup) — graceful for dev/staging
- **Optional fail-fast:** `builder.AddPrismKeyVault()` retained as opt-in for explicit validation
- **Health check:** `PrismKeyVaultHealthCheck` with 30-second caching, sanitized responses, `["prism"]` tag filtering
- **Security:** Copper's comprehensive threat model applied; credential exposure, DoS amplification, information disclosure mitigations documented

### 2. Improved Key Vault Error Messages (Blathers + Tangy)
- **401 handling:** Now correctly identified as configuration error (wrong Managed Identity, not logged in)
- **403/404 handling:** Distinct non-retryable errors (no access to secrets, secrets missing)
- **Transient errors:** Explicit "temporarily unavailable" message after SDK retries exhausted
- **Constants extraction:** `SigningKeySecretName`, `EncryptionKeySecretName` as single source of truth
- **Atomic assignment:** Both secrets fetched to locals before either written to options (no half-configured state)
- **Security:** No secret names, vault URIs, or credential chain details in error messages

### 3. Community Governance (Mabel)
- **CONTRIBUTING.md:** PR workflow, code standards, security reporting, solo maintainer transparency
- **FUNDING.yml:** GitHub Sponsors link (jonnymuir) — legitimacy signal for versioned marketplace package
- **Rationale:** 4 releases + detailed CHANGELOG + professional README + CI/CD already in place; these files formalize maturity

### 4. Documentation Update (Mabel)
- **biometric-setup.md:** Production setup now leads with `Prism:VaultUri` config; error code reference (401/403/404)
- **umbraco-setup.md:** Clarified Program.cs only requires `builder.Services.AddPrism()`; `AddPrismKeyVault()` optional
- **Added:** Fail-late behavior explanation, post-deployment smoke test recommendation, security considerations section

### 5. Version Bumping (Blathers)
- Bumped from 1.4.0 → 1.5.0 across:
  - `src/UmbracoPrism.Core/UmbracoPrism.Core.csproj`
  - `package.json`
  - `umbraco-marketplace.json`
  - `CHANGELOG.md` (comprehensive v1.5.0 release notes)
