## Summary

Completed end-to-end implementation of media picker for tenant branding editor CSS variables, with parallel backend seeding infrastructure.

### Frontend: Media Library Picker (Isabelle)

**Objective:** Add image selection capability to `type: image` CSS variable inputs in tenant branding editor.

**Implementation:**
- Integrated Umbraco Media Picker Modal (`UMB_MEDIA_PICKER_MODAL`) into branding editor UI
- Added thumbnail preview with `url()` unwrapping for display
- GUID-to-URL resolution via Umbraco Management API (`GET /umbraco/management/api/v1/media/{id}`)
- Free-text URL input fallback for advanced users or external URLs
- Clear button to reset values
- CSS `url()` wrapping applied automatically when selecting from media library

**Decision:** Media library picks are wrapped in `url('...')` format (required for CSS background-image), while free-text input stores values as-is (allows plain URLs or pre-formatted values).

**Quality:** Build clean, 0 TypeScript errors.

### Backend: Seed Media & Content Type (Blathers)

**Objective:** Provide seeded hero image and content type definition on first startup.

**Implementation:**
- `SeedBrandingMedia()` in `PrismStarterContentSeeder`: idempotent creation of "Prism Branding" media folder and "Hero Background" image
- Seed image asset committed to `wwwroot/media/branding/` (gitignore exception carved out)
- `PrismContentTypeSeeder` now seeds `heroImage` (Media Picker 3) property on `homePage` doc type
- Seeded Home page assigned the heroImage UDI on creation
- Deterministic GUID keys for idempotent re-runs

**Conventions Adopted:**
- Seed media assets live under `wwwroot/media/branding/`
- All media seeding is idempotent: check for existence before creating
- Use `GetPagedChildren()` — not `GetChildren()` (unavailable on IMediaService in Umbraco 17)
- Avoids external download; keeps repo self-contained for CI and offline dev

**Quality:** 218 tests pass; build clean.

## Decisions Logged

1. **Media Library Picker — Image Variable CSS Format** (Isabelle)
   - Picker selections → wrapped in `url('...')`
   - Free-text input → stored as-is
   - Rationale: CSS background-image requires url() syntax; picker is always CSS usage; free-text is for power users

2. **Static wwwroot seed assets for Umbraco media library** (Blathers)
   - Commit seed images to repo under `wwwroot/media/branding/`
   - Rationale: Self-contained, CI-friendly, offline dev support
