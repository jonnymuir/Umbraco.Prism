### Key Decisions

**Plugin Selection:**
- Biometric Authentication: `@aparajita/capacitor-biometric-auth@7.x`
- Secure Credential Storage: `@aparajita/capacitor-secure-storage@7.x`
- Rationale: Active maintenance, comprehensive iOS/Android support, strong TypeScript types, built-in fallbacks

**Rejected Alternatives:**
- `@capacitor-community/biometric-auth` (less active maintenance)
- `capacitor-biometric-auth` (unmaintained pre-Capacitor 5)
- `@capacitor/preferences` (no encryption)
- `capacitor-secure-storage-plugin` (stale Capacitor 5 era)

**Platform Entitlements Auto-Injection:**
- iOS: Inject `NSFaceIDUsageDescription` in bootstrap-ios.sh (perl regex)
- Android: Inject `USE_BIOMETRIC` permission in bootstrap-android.sh (perl regex)
- Convention: Idempotent auto-injection reduces operator error

**Registration Flow (Post-OIDC Enrollment):**
1. WebView OIDC callback detects token receipt
2. Check biometric availability via `BiometricAuth.checkBiometry()`
3. User prompt: "Enable {FaceID|TouchID|Fingerprint}?"
4. Confirmation auth (user validates identity)
5. Store refresh token in SecureStorage
6. Graceful fallback if unavailable

**Login Flow (Launch-Time Authentication):**
1. Check if credential exists in SecureStorage
2. Prompt biometric authentication
3. Retrieve refresh token on success
4. Exchange with Entra `/token` endpoint
5. Inject access token into WebView session
6. Load WebView with session established

**Fallback Paths:**
- User cancels → silent fallback to web login
- Biometric lockout → error message + web login
- Refresh token expired → clear credential + web login

**MobileBundleService Changes Required:**
1. Add plugins to `dependencies` in generated package.json

4. Update bootstrap scripts for auto-injection
