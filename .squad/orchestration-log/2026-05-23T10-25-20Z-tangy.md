## Desktop Behavioral Contract

**User-observable behavior:**
1. `.graph-canvas` scrolls both vertically AND horizontally
2. Shell chrome (outline, inspector, confidence tabs) remains anchored
3. Scrollbars appear when content exceeds canvas viewport
4. Shift+wheel for horizontal scroll, two-finger trackpad for natural panning
5. Zoom + many lanes: all lanes remain reachable via scroll

**Accessibility:**
- Keyboard: Tab to canvas, arrow keys for stage navigation, Shift+Arrow for viewport scroll
- Ctrl+Home/End for scroll boundaries
- Focus ring visible at canvas edges
- Screen reader announces: "Role-first workflow editor workspace with {N} lanes, vertical and horizontal scrolling"

## Mobile Behavioral Contract

**User-observable behavior:**
1. Stacked layout: outline, canvas, inspector in vertical stack
2. Canvas occupies full width (no 240px/380px sidebars)
3. Outline and inspector collapsed by default, expand via toggle buttons
4. Natural touch pan (horizontal + vertical) within canvas
5. Lane widths remain fixed; mobile users scroll to see all lanes

**Accessibility:**
- Touch: single-finger pan, double-tap to open inspector, long-press for context menu
- Screen reader: drawer toggles announce state, drawers trap focus when open
- External keyboard: same keyboard contract as desktop
