## Summary

Blathers investigated and addressed the "Inadequate permissions" error when running `dotnet workload install aspire` on macOS with a root-owned .NET SDK installation. The issue arose because the SDK base path (`/usr/local/share/dotnet`) is owned by `root:wheel`, requiring elevated privileges for workload installation.

## Work Completed

### Investigation
- Confirmed `.NET SDK installed at /usr/local/share/dotnet/sdk/10.0.102/` with `root:wheel` ownership
- Verified no workloads were installed locally
- Documented Microsoft's requirement for elevated privileges on macOS/Linux for protected SDK directories

### Implementation  
- **README.md**: Added note about elevated permissions on macOS when SDK is in protected paths
- **ASPIRE_DEV.md**: Updated with explicit `sudo dotnet workload install aspire` guidance
- **scripts/validate-aspire-prereqs.mjs**: Enhanced preflight validator to provide actionable guidance when SDK is protected
