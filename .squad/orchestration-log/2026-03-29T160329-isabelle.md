### Decision Rationale

The unauthenticated hero section rendered two "Sign In" buttons on mobile devices running inside the Prism mobile shell:
1. The primary `btn-primary` CTA (always visible)
2. The hidden-then-revealed `btn-mobile-signin` (visible only under `html.prism-mobile`)

This created a silent duplication hard to spot in code review. Decision: **Do not use hidden/revealed buttons as a pattern for mobile-specific auth CTAs.** The primary CTA already gets full-width layout in mobile mode via grid. If a future mobile variant is needed (e.g., biometric shortcut), introduce it as a distinct named element with a unique label.
