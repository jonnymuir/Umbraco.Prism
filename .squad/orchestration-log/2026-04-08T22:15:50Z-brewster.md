### Key Decisions

1. **RuntimeMode Toggle** — Configuration-based switch between emulator and Core runtime
2. **Namespace Separation** — Emulator features under `MockBackOffice.Workflow.*`, never leaking into Core contracts
3. **Seed Packs** — JSON-based workflow + data fixtures for reproducible scenarios
4. **Deterministic Personas** — Demo-only operators with fixed identities (never production)

### Rationale

Enables MockBackOffice to serve dual purpose: standalone demo sandbox AND integration test harness. Namespace separation prevents accidental demo-only shortcuts from polluting production contracts. Seed packs enable repeatable demos and faster feedback loops.
