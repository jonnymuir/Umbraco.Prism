2. **JSON Storage** — Workflow graph and field definitions stored as JSON columns (demo-appropriate)
3. **Append-Only Audit** — `WorkflowEvent` table immutable; events never updated/deleted
4. **Concurrency** — Optimistic locking via `RowVersion` on state-mutating tables
