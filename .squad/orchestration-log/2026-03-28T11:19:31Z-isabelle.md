# Orchestration: Isabelle SecurityError Blob URL Fix

**Timestamp:** 2026-03-28T11:19:31Z  
**Agent:** Isabelle (Frontend Dev)  
**Task:** Fix SecurityError blob URL download bug in prism-create-tenant-modal.ts

## Summary

Fixed blob URL download failure affecting "Produce Mobile" feature. Root cause was SPA router interception of programmatic download anchor clicks, attempting history.pushState() on blob: URLs.

## Changes Made

**File:** `src/UmbracoPrism.Client/src/prism-create-tenant-modal.ts` (lines 793-851)

1. Added `target="_blank"` to download anchor element
2. Added `rel="noopener noreferrer"` security attribute
3. Implemented `preventDefault()` and `stopPropagation()` in button click handler

## Root Cause

Umbraco SPA router (activated by UmbracoApplicationUrl config in commit 1250cf2) intercepts all `<a>` click events for client-side navigation. When the download anchor was clicked, the router captured the event and attempted `history.pushState()` on the blob: URL, which browsers reject for security.

## Consequence

- ✅ Downloads now work without navigation or SecurityErrors
- ✅ Pattern is reusable for any blob-based downloads (PDFs, images, CSVs, etc.)
- ✅ Follows security best practices with proper rel attributes
