- PII protection strategy (tenant-scoped encryption, redaction in logs)

### Key Decisions

1. **Centralized Tenant Guard** — ALL instance/task lookups through `IWorkflowTenantGuard`; return 404 on cross-tenant access
2. **Role-Based Authorization** — `WorkflowActor` enum with `AllowedActors` flags per transition
3. **Member Ownership** — Member role requires instance `MemberId` match; Operator role requires `role=prism-operator` claim
4. **Existence Concealment** — 404 response (not 403) prevents information leakage

### Rationale

Centralizes security enforcement, preventing developer error in direct DB queries. 404 responses conceal instance existence across tenants. Pattern mirrors existing `DeviceAdminController` tenant isolation. Single point of enforcement simplifies security audits.
