## Decision Merged

- **File:** `.squad/decisions/inbox/isabelle-mobile-nav-audit.md`
- **Title:** Always HTML-encode JSON in HTML attributes (Razor)
- **Status:** Proposed → Merged

### Key Points
- `System.Text.Json` produces `"` delimiters which break `attr="..."` HTML syntax
- Always use `@Html.AttributeEncode()` when passing JSON into a double-quoted Razor attribute
- Browser decodes `&quot;` → `"` before returning `getAttribute()`, so `JSON.parse` sees valid input
- Single-quote fallback works but is unsafe if label text contains single quotes
