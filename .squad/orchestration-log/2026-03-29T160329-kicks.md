### Technical Context

- **Problem:** Jonny deployed app to iPhone, signed in via Entra, but no Face ID enrollment prompt appeared. On reopening, full Entra login required every time.
- **Root causes:** 
  1. `biometric-bridge.ts` tried to parse empty response from `/exchange`
  2. `www/index.html` bootstrap never attempted biometric auth on startup
  3. No enrollment trigger after Entra login
  4. Missing CORS headers on `/exchange` for Capacitor origins
- **Key insight:** `PrismMemberCookie` is `SameSite=Lax`, so Set-Cookie IS stored from cross-origin fetch (with `credentials: 'include'`), and IS sent on top-level navigation. No session token is returned; session is established via cookie alone.
