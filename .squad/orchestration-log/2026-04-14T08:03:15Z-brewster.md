- Transient `/` route resolution during cold boot is a startup convergence artefact, not normal steady-state Umbraco routing
- Emerges from interaction between fresh runtime provisioning, development seeding, publish/cache convergence, and immediate route consumption in Razor

**Readiness Strategy:**
- Use `/api/prism/downstream-demo/seed-contract-ready` as authoritative gate (reports `routeContractReady: true`)
- Use home-page `data-prism-home-ready="true"` as smoke check only
- Keep behaviour assertions strict once contract reports ready

**Dashboard CTA Pattern:**
- Public CTAs for protected content should pass authored URL as login `returnUrl`
- Removes ambiguous intermediate states; aligns TestSite with authored Umbraco navigation
- Example: `HomePage.cshtml` now derives `Go to Dashboard` link from content-resolved dashboard URL

**Why This Matters:**
- Avoids over-diagnosing startup transients as platform behaviour
- Helps future fixes target readiness/fallbacks and startup sequencing
- Narrows flake investigations: bounce to `/` after sign-in now points away from CTA wiring
