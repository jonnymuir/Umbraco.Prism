# Prism developer guides

Guides for building on Umbraco Prism. The full list of Prism documentation is in the
[documentation index](../README.md).

- **[Extending Prism for your business domain](./extending-prism.md)**: add your own endpoints,
  notifications and handlers inside Prism's tenancy, using the reference site's record shop as
  the worked example.
- **[GOV.UK Frontend token bridge](./govuk-token-bridge.md)**: recolour GOV.UK Frontend
  components with a tenant's brand palette.
- **[Mobile app CI/CD pipeline](./mobile-app-ci-cd-pipeline.md)**: generate, sign and upload the
  reference mobile app to TestFlight from GitHub Actions, with the secrets and variables it needs.

Service blueprints, the calculation language and the visual editor are documented in
[Wayfinder's guides](https://github.com/jonnymuir/Wayfinder/blob/main/docs/guides/README.md), and
hosting them in Umbraco in [Wayfinder.Umbraco](https://github.com/jonnymuir/Wayfinder.Umbraco#readme).
