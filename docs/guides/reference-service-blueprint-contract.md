# Reference Service Blueprint Contract

This guide has moved. The entire service-blueprint surface (the engine, the calculation
language, the rendering toolkit, and the editor) now lives in the
[`jonnymuir/Wayfinder`](https://github.com/jonnymuir/Wayfinder) and
[`jonnymuir/Wayfinder.Umbraco`](https://github.com/jonnymuir/Wayfinder.Umbraco) repositories — see
this repo's own `CLAUDE.md` for why. `UmbracoPrism.Core` carries no service-blueprint opinion of
its own; `UmbracoPrism.TestSite` consumes `Wayfinder.Umbraco` directly, the same way any other
host would.
